# Project images
Put one image per project here, each a **two-page spread (about 2:1, e.g. 2000x1020), WebP**.
Name them to match the `img` paths in the PROJECTS list in index.html:
`plate-01.webp`, `plate-02.webp`, ...
Optional smaller versions for phones (about 900 px wide) such as `plate-01-sm.webp` can be set with `imgSm`.
Left half of the image becomes the left page, right half the right page. Keep important detail away from the centre fold.
Until a file exists, that plate shows a labelled placeholder.
